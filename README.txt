MS. CROSBY ELL DASHBOARD — SETUP INSTRUCTIONS
================================================

WHAT'S IN THIS ZIP
-------------------
- index.html          Complete, ready-to-use page shell (built fresh — wires up every script + the CSS)
- style.css           All dashboard styling, including the Picture Books / Savvas myView section switch
- unit1.js .. unit5.js         5 picture-book units, 25 lessons total (Push-In + Pull-Out each fully scripted)
- savvas_u1.js .. savvas_u5.js  Savvas myView curriculum, Units 1-5, 6 weeks each, Below/On Level x Push-In(60min)/Pull-Out(30min)
- app.js              Full dashboard logic: sidebar, tabs, section + level + mode toggles, localStorage, print, crash-guard

HOW TO INSTALL
---------------
1. Drop ALL files from this zip into one folder (this can be a brand new folder — index.html here is complete on its own).
2. If you already have a GitHub Pages repo, just overwrite index.html, style.css, and app.js with these versions, and add all 10 unit/savvas .js files alongside them.
3. Push to GitHub / your host. No other setup needed.

WHAT'S IN THE DASHBOARD
-------------------------
- Picture Books section: 5 thematic units (Who We Are, Our Natural World, Family & Culture, Facing Challenges, Problem Solving), 25 fully detailed lessons with I Do / We Do / You Do / Vocabulary / Differentiation / 5-Day Plan, each with genuinely distinct Push-In and Pull-Out versions.
- Savvas myView section: the real myView Units 1-5 (Environments, Interactions, Heroes, Events, Solutions), 6 weeks each, Below Level + On Level, each with a 60-min/5-day Push-In plan and a 30-min/4-day Pull-Out plan (Day 1 is always whole-group — pull-out groups never get a cold intro to new content).
- Toggle between sections and levels with the header buttons — everything saves to localStorage automatically.

Questions or something looks off? Just ask in the chat — re-paste the latest Code-tab text into this tool any time you want a fresh zip.
